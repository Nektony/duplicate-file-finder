# Changelog

All notable changes to Duplicate File Finder will be documented in this file.

## [9.2] - June 2026

- A redesigned start screen makes adding folders and starting a scan easier than ever.
- A new category selector lets you pick exactly what to look for, from photos and videos to similar folders, and you can now limit the search to specific file extensions.
- Scanning is noticeably faster across the board, VoiceOver works smoothly throughout, and we've fixed bugs to keep things stable.


## [9.1] - June 2026
- The photo similarity level is now adjustable, so the search for similar photos returns exactly the results you're after. 
- Duplicate paths can now be shown without the file name, which keeps long paths readable instead of getting cut off.
- Information about similar images has moved next to the file name, freeing up more room for the preview itself.
- On top of that, we addressed a number of small inconveniences in everyday use.


## [9.0.1] - April 2026

### Fixed
- Minor refinements and bug fixes

## [9.0] - April 2026

### Improved
- Redesigned interface
- Select by Folders
- Full VoiceOver support
- Stability

## [8.5.3] - February 2026

### Improved

### Improved
